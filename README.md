# 微信本机 Codex 助手

把微信变成电脑上 Codex 的移动入口：手机发自然语言任务，本机执行，进度、文件和验证结果回到同一微信私聊。

## V0.1 范围

- 微信文字任务与简洁进度回执
- 本机文件查找、入站、出站与哈希校验
- 主任务状态、暂停/继续、里程碑和验收
- Codex 任务调度桥、互斥租约、陈旧任务恢复与健康检查
- PDF/PPTX/Markdown/图片/音视频的受控处理入口
- 可配置的额度门禁、工作时段许可与检查点续跑

## 明确不包含

- 不绕过 Codex/OpenClaw 的账号、额度或权限限制
- 不自动付款、登录、删除重要资料或公开发布
- 不把本机凭据、聊天数据库、用户文件或运行记录放进代码仓库
- 本机合成测试不能替代真实手机端到端验收

## 快速开始

1. 阅读 [INSTALL.md](INSTALL.md) 并完成 OpenClaw、Codex 与微信频道配置。
2. 在 PowerShell 中先运行 `scripts/release-self-test.ps1`；配置完成后再运行 `scripts/self-test.ps1`。
3. 确认基础测试全部通过后，从本人微信私聊发送一个低风险测试任务。
4. 按 `docs/TEST-MATRIX.md` 完成真实手机验收，再启用持续任务。

当前版本是发布候选开发版；在真实新机安装和手机闭环完成前，不应对外宣称“一键安装”或“完全无人值守”。
