# 验收矩阵

| 层级 | 检查 | 通过标准 |
|---|---|---|
| 发布包 | `scripts/release-self-test.ps1` | 发布审计、全部合成回归和干净目录初始化通过，`livePhoneTest=false` |
| 安装 | `scripts/initialize-workspace.ps1` 在空目录连续运行两次 | 首次只创建模板与运行目录；再次运行不覆盖、不新增、不写入凭据 |
| 前置 | `scripts/preflight.ps1` | 无缺失、未配置或关键未知状态 |
| 主聊天路由 | `test-task-chat-registry.ps1` | 相同绑定幂等，不同临时会话重绑被拒绝；交接包携带 canonical-only 策略与主会话哈希 |
| 调度 | `test-dispatch-bridge.ps1` | busy、写锁、网络失败、恢复失败、临时会话和引用不匹配均失败关闭；阻断时不建下游记录，篡改包、旧令牌、错误 worker 和损坏记录均被拒绝 |
| 微信文字 | 手机发送低风险任务 | 同一私聊收到开始、结果和验证说明 |
| 微信文件 | 图片/PDF 入站与小文件出站 | 原件不覆盖，副本哈希可核对，附件可打开 |
| 控制 | 停止后继续 | 停止时不再执行；继续从记录的下一步恢复 |

每次发布必须记录具体环境、时间和证据。未执行的项目标记为“未验证”，不得写成通过。
